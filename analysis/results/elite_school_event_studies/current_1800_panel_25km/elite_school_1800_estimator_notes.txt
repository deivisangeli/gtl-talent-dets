=== Estimator comparison on the 1800+ panel ===

Current main estimator in analysis_elite_school_1800.R:
- did::att_gt with est_method = 'dr', base_period = 'universal',
  and not-yet-treated controls.

Alternative estimators added here:
- BJS imputation via didimputation::did_imputation
- BJS imputation with cohort-specific linear first-stage trends
- Wooldridge ETWFE via etwfe::etwfe + emfx

Important comparability note:
- Callaway-Sant'Anna and both BJS specifications are using not-yet-treated logic.
- The Wooldridge implementation here uses never-treated counties as the
  reference group (gref = 0) to recover a full event-time path.

- To align event-time reporting with the universal-base CS output, the
  normalized -10 decade is shown explicitly at zero if an estimator
  does not return it.
