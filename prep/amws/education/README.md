# AMWS four-edition education pilot

For the additive all-earned-postsecondary extension and the refreshed
college-allocation outcomes, see [postsecondary qualifications](POSTSECONDARY.md).
It adds other bachelor/master/doctoral qualifications and postsecondary
credentials while preserving this frozen pilot and its existing four families.

The latest extractor is `education_regex_v04.py` (`multi_v04`), written after a
manual audit of 150 unknown-training entries. It recovers damaged `Educ`
headings, removes false `Am`/`Md`/1955 name-header awards and excludes board
certifications. Its release is `amws_education_postsecondary_v04_20261019`,
built by `build_postsecondary_release_v04.py`. The audit, rules, validation and
refreshed outcomes are in the last two sections of
[POSTSECONDARY.md](POSTSECONDARY.md). The frozen `multi_v03` parser described
below and all of its releases are unchanged.

The newest release is `amws_education_postsecondary_v06_20261021` (`build_postsecondary_release_v06.py`): v05 with
2,178 duplicate entries removed (see the last section of [POSTSECONDARY.md](POSTSECONDARY.md)). Before it,
`amws_education_postsecondary_v05_20261020` was built by
`build_postsecondary_release_v05.py` on top of v04 without re-parsing. It adds the
top-500 manual institution matches, the medical-campus overrides, an unmatched
store and the 1986 physical-science classification. See the last section of
[POSTSECONDARY.md](POSTSECONDARY.md).

This pilot uses 250 newly sampled full-edition entries each from1906,1938,1955,
and1986. The1986 draw excludes the previous1,000-record pilot. It does not
enrich or rewrite estimation sources or panels.

The shared data root comes from `TALENT_DETS_DATA_DIR`, falling back to the
current user's `Globtalent Dropbox/gtl_talent_dets` directory. All output is
under `output/amws/education_pilot/multi_edition_regex_pilot/` in that root.

## Reproduction

Use the bundled Python runtime and an R installation with haven/readxl/readr.
From the repository root, run:

```text
Rscript prep/amws/education/ingest_early.R <data-root> <pilot-output>/ingestion
python prep/amws/education/sample_pilot.py
python prep/amws/education/report_pilot.py --preservation
```

Sampling uses one `random.Random(42)` over ascending editions and sorted
source keys. Splitting uses a separate seed42 generator. Each edition has200
development and50 held-out records. Identical biographies and exact
normalized full-name/birth-year links are grouped; a constrained binary
allocation preserves quotas if a group would otherwise cross partitions.
Surname/initial/near-birth links are flagged rather than assumed identical.
The manifest records the algorithm, keys, links, checksums, and membership.

Manual review is **not** regenerated by a classifier. `review_*.jsonl` contains
explicit full-biography decisions, including negatives. `pilot_io.ManualBatch`
validates literal evidence. `adjudications_*.json` preserves reference changes
and their reasons. The reviewed sample and degree ledger compile these files.

```text
python prep/amws/education/pilot.py reference
python prep/amws/education/pilot.py develop baseline_v08
python prep/amws/education/pilot.py develop <new-rule-version>
python prep/amws/education/pilot.py freeze <selected-rule-version>
python prep/amws/education/pilot.py holdout
python prep/amws/education/report_pilot.py
```

The baseline is the unchanged frozen1986 v08 parser. Every subsequent version
gets an immutable snapshot, predictions, metrics, errors, and manual error
review. Development stops at95% complete-tuple precision and90% recall in
each edition, or two consecutive improvements below0.5 percentage points in
the equally weighted mean of edition-specific all-target tuple F1. Freeze
locks parser, reference, and split hashes. The heldout runs once; development
is disabled after freeze.

## Parser and measures

`education_regex.extract(text, birth_year=None, edition=1986)` returns record
status/flags and awards with literal labels, school names, date tokens,
resolved award years, honorary status, rule IDs, flags, and evidence offsets.
Offsets index the unchanged decoded Python Unicode string. No external school
lookup, person-specific rule, or sample-specific override is used.

Sources are1906 workbook column6,1938 field `a`,1955 field `original`, and1986
`raw_text_adjusted`. The source binary files remain intact. Invalid UTF-8
strings in1955 are decoded as Latin1 and explicitly logged; already-valid
strings are retained. `raw_text` remains available for diagnostics.

Families distinguish BA/BS, other bachelors, academic/professional masters,
and PhD/DPhil. Other doctorates and credentials remain separate in the manual
reference. Honors qualifications are earned; explicit honorary awards are
excluded from earned-degree measures. Bare attendance and employment dates
are not award dates.

Resolved two-digit dates must be unique under the edition date and trusted
canonical birth/biographical chronology. Missing canonical birth is not
replaced by an arbitrary century pivot. Partial or ambiguous extraction is
retained with literal text and flags.

Metrics match exact family/field keys one-to-one, normalizing only case,
punctuation, and whitespace for comparison. Extra duplicate predictions are
false positives. Missing reference fields are excluded from that field's
recoverable denominator; coverage among all sampled records is reported
separately. A complete tuple requires both school and resolved year.

`balanced_all` pools an equal-record allocation across editions. It is not an
edition-size-weighted population estimate. Precision/recall have Wilson95%
intervals; award intervals assume independent awards. F1 has seeded,
edition-stratified record-bootstrap intervals. Proportions in CSVs are0–1;
the findings report prints percentages.

The heldout is protected from regex tuning, not from the initial manual
biography reading. Preserve this limitation when reporting accuracy. Do not
tune using the held-out error table; use a new independent pilot if further
revisions are needed.

`not_an_institution`. Clear is a text-cleanup judgment, not verified identity.
The release report records coordinator review, source preservation, and timing;
it does not alter the paused OpenAlex research or production geolocation files.

Set `TALENT_DETS_DATA_DIR` to the configured Dropbox project root and, when
needed, `GTALLOCATION_DATA_DIR` to the GTAllocation Dropbox project root.
`RSCRIPT_PATH` overrides the installed Rscript used for candidate scoring.
No geocoding service or outside coordinate source is used.

```text
python prep/amws/education/institution_geolocation.py prepare
python prep/amws/education/institution_geolocation.py candidates
python prep/amws/education/institution_geolocation.py baseline
# Complete explicit development review before freezing.
python prep/amws/education/geolocate_education.py freeze
# Complete the separate final audit before publishing.
python prep/amws/education/geolocate_education.py publish
python -m unittest discover -s prep/amws/education -p "test_*.py"
```

The primary reference is GTAllocation's OpenAlex snapshot under
`Data/external/oa_snapshot/data/institutions/`: 23,885 education institutions
with valid coordinates. Canonical/alternative names can authorize guarded
unique exact matches; acronyms require review. `master_alias_oa.csv` and
`OA_revelio_shanghai.csv` supply candidates with provenance only, including
their review flags. Malformed or absent IDs are rejected. Separate aliases of
one ID do not create artificial ambiguity; candidates are reduced to five
distinct IDs with installed R `stringdist` Damerau–Levenshtein scores.
Baseline fuzzy acceptance requires 96/100 and an eight-point distinct-ID lead.
Later iterations improve exact matches using reviewed aliases and versioned
institutional abbreviations/OCR rules; the baseline fuzzy rules stay fixed.
Stored baseline candidate scores are not recalculated under later exact-only
normalizations. Matching does not strip campus qualifiers or automatically
split conjunctions such as William and Mary.

Manual review uses `geolocation_review.ReviewBatch`: read **all** supplied
education contexts and record explicit verdicts with `add()` and `save()`.
No automatic classifier supplies review verdicts. Development batches A–D cover
1,018 distinct names: top100, a seeded500 proposed-match audit,250 frequent
unresolved names and250 random residual names, with overlaps deduplicated.
Primary-source links document historical/collision decisions. Changes to prior
decisions use correction JSONL logs, preserving old/new decisions and reasons.
Verified aliases are global only when identity is unconditional. Conditional
rules use reliable reported years, edition or education evidence. Missing or
chronology-conflicting years fail date conditions. Another person's entry,
birthplace or employment address cannot determine the university.

`freeze` saves geo_v02–geo_v05 predictions/rules/metrics, verifies at least 99%
development confirmed-match precision and the coverage plateau, and draws a
separate seed1042 audit of500 previously unreviewed accepted strings and200
unresolved strings. Use `ReviewBatch('final_A')` through `final_D` for that
audit. Frozen rules and predictions are checksummed and unchanged thereafter.
Individual audit corrections may affect only their explicitly reviewed names;
they are not propagated as new rules. Failed 99% final precision demotes all
unreviewed automatic name mappings, including propagated alias variants, to
`candidate_requires_review`. This gate requires both name-level and
award-weighted point estimates to reach 99%; Wilson and name-cluster bootstrap
95% intervals are also reported.

Outputs under `output/amws/education_geolocated/`:

Coverage counts unique source-award positions, not duplicated person-file rows.
Name-level audit precision conservatively treats conditional, ambiguous and
invalid-extraction cases as unconfirmed unconditional matches. Award-weighted
precision weights these name judgments by their total ledger award frequency;
its interval resamples names, not independent awards. The unmatched audit
reports missed matches, not population recall. Coverage is a census of the
enriched ledger and has no sampling interval; accuracy intervals belong to the
random audit. Original regex extraction accuracy is a separate limitation.

All coordinates must exactly match an eligible education record in the
checksummed snapshot. They describe the supplied current reference location,
including relocations or recorded reference-coordinate errors, not the campus
where a historical degree was taught. Explicit incompatible campuses and
parent/subunit substitutions remain unresolved. Impossible inherited award
associations may have geocodes withheld while original education fields remain
intact. No existing source, pilot, enriched file, GTAllocation input or estimation
panel is rewritten. Publication verifies the previous enrichment preservation
manifest as well as this run's input checksums.

The completed run froze `geo_v05`. The independent audit confirmed 476/500
proposed names: 95.20% precision (95% Wilson interval 92.96%–96.75%) and
98.57% award-weighted precision (95% name bootstrap 97.35%–99.40%). The 99%
gate failed. Of 200 unresolved audited names, 140 had recoverable unconditional
matches and three had conditional matches. Explicit audit decisions were
integrated without changing frozen rules; 1,355 unreviewed name mappings remain
candidates. Final publication locates 153,386 institution-bearing awards
(53.47%), representing 1,470 original strings and 709 reference institutions.
The five copies contain 136,876 person-file rows, including all original
duplicate geographic candidates. Coverage is 32.9%, 36.8%, 38.6% and 63.8%
for 1906, 1938, 1955 and 1986 respectively.

Validation checked 559 protected files, all 292,961 exact award evidence/label
spans, original cell/row/order preservation, aligned arrays and direct gzip
snapshot agreement for all 709 published IDs and coordinates. The 65 tests
include publication regressions for historical namesakes, foreign collisions,
honorary OCR leakage and impossible inherited graduate degrees. The local
artifact regressions use `geolocation_regression_cases.json`; they verify
explicit reviewed publication decisions and do not tune the frozen rules.

**Entry and duplicate policy.** `source_key` is `edition:original identifier`:
`lineid` for 1906/1938/1955 and `entry_id` for 1986. Entries are not linked across
editions. For duplicate source keys, prefer the existing combined geocoded file,
then the unmatched 1906, 1938 and 1955 files, then the separate 1986 file; within
each file, select the first occurrence. The combined dataset is sorted by numeric
edition and original identifier. Its original fields come unchanged from that
selected row; union-schema fields absent from the selected source remain blank.
In particular, the original `edition` column can be blank: derive edition from
`source_key`. Every alternate row remains in provenance; source-specific copies
retain all duplicates. This policy selects an export row without reassessing

**Award columns.** `{family}_award_{n}_...` retains the existing earned-degree

**Entry summaries.** `oa_ids` is the JSON union of IDs applied across the entry's

### Canonical analysis input: amws_open_alex

The canonical combined input is
`Data/processed/amws/amws_open_alex.csv` under the Dropbox project root.
It is an edition-aware US-born subset of
`output/amws/amws_education_openalex_coordinates_20261014/amws_all_editions_education_openalex.csv`.
The validated source release retains all 156,139 entries. The canonical input
contains 136,489 entries and the same 444 columns: all 56,831 entries from
1906/1938/1955, plus 79,658 1986 entries with a normalized `is_us_birth` value of
`TRUE`. Edition comes from `source_key`, because the original `edition` column
can be blank. Only the 1986 component is filtered; blank US-birth flags in
earlier editions do not cause exclusions. Normalization trims whitespace and
ignores case. False, missing and unrecognized 1986 flags fail the filter and
are counted separately; the current source excludes 19,650 false flags and
has no missing or unrecognized 1986 flags. Citizenship is neither recorded nor
inferred.

The neighboring `amws_open_alex_manifest.json` records the source release/file,
source and destination SHA-256 checksums, publication date, filter rule,
before/after counts by edition, dimensions, OA coverage, test results and
reference-coordinate qualification. Its `byte_identical` flag is now false
because rows are removed; every retained cell and relative row order are
verified unchanged. The immutable full release provides the unfiltered archive.
